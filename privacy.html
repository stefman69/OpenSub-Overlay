# OpenSub Overlay Privacy Policy Last updated: August 9, 2026 OpenSub Overlay is a browser extension that detects, imports, translates, stores, and displays subtitles for videos on websites. ## Data OpenSub Overlay accesses To provide its subtitle functionality, OpenSub Overlay may access: * The URL and title of webpages containing videos * Video-player and subtitle information available on webpages * Subtitle and caption text * User-selected subtitle files * Source and target language selections * Subtitle timing offsets and display preferences * Saved associations between webpages and subtitle tracks ## How this data is used This information is used only to provide the extension's user-facing subtitle features, including detecting subtitles, translating subtitle text, displaying subtitle overlays, remembering subtitle settings, and maintaining the user's local subtitle library. ## Local processing and storage OpenSub Overlay stores subtitle data, webpage associations, and user preferences locally using Chrome extension storage. OpenSub Overlay does not operate a developer-controlled server and does not transmit subtitle libraries, browsing history, or saved settings to the developer. Translation and language detection use browser-provided APIs when available. ## Data sharing OpenSub Overlay does not sell user data. OpenSub Overlay does not share user data with advertisers, data brokers, analytics providers, or other third parties for advertising or profiling purposes. Data accessed by the extension is used only as necessary to provide its subtitle-related functionality. ## Remote code OpenSub Overlay does not download or execute remotely hosted JavaScript or WebAssembly. All executable extension code is included in the extension package. Subtitle files and timed-text responses obtained from webpages are treated as data and are not executed as code. ## Data retention and deletion Saved subtitle tracks, translations, webpage associations, and settings remain in the user's local Chrome extension storage until the user removes them, clears the extension's stored data, or uninstalls the extension. Users can remove saved subtitle entries through OpenSub Overlay's subtitle library. ## Chrome Web Store Limited Use OpenSub Overlay's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide or improve OpenSub Overlay's disclosed subtitle detection, translation, storage, and display functionality. ## Changes to this policy This privacy policy may be updated when OpenSub Overlay's functionality or data-handling practices change.
